# 工作流：从参考图到成品

## 五个阶段（按顺序，不要跳）

1. **解剖参考图** —— 先看图并写下：区域划分、视觉层级（谁最大、谁最重）、色板（取 5–7 个十六进制）、字体气质、装饰语言。产出 `analysis.md`。
   - 不写这一步直接开画，主场景通常要返工 5 轮以上（实测）。
2. **灰模** —— 只放占位灰块 + 假字条，确认网格、信息密度、留白。**这一步不碰颜色和细节。**
3. **上色** —— 填 theme 色板，确认对比度（`check.py` 会断言）。
4. **上字** —— 真文案、真字号、避头尾；此时才判断行宽与层级。
5. **精修与验收** —— 装饰、阴影、颗粒；跑 `check.py`，再按 `--for publish` 出终稿。

## 清晰度档位（实测，1080×1440、21 个区块）

| 档 | ss | 输出 | 耗时（热态） | 用途 |
|---|---|---|---|---|
| `draft` | 1 | 1× | <0.3s | 看版式、调坐标 |
| `preview` | 2 | 2× | ~1.6s | 确认观感 |
| `publish` | 3 | 3× | ~2.7s | 交付，大弧/细线才够平滑 |
| `print` | 1 | PDF 矢量 | ~1.3s（A4） | 印刷；文字不可选 |

冷启动另加约 6s（首次解析 4 个字体文件），之后同进程复用。

**要点**：`publish` 默认输出 3× 像素而**不降采样**——因为纯 Python 降采样占总耗时 77%，
而查看器/平台缩放的效果更好。需要精确尺寸时才用 `exact=True`（慢 2–3 倍）。

印刷档 ss 固定 1：A4@300ppi 已经是 2480×3508，ss=3 会让耗时从 1.3s 涨到 52s（实测）。

## 性能经验

- **半透明叠加按「单色 LUT + bytes.translate」走 C 层**：暗角这类大面积灰/黑叠加
  逐像素浮点运算实测 6.6s（占 71%），改成 256 项映射表 + translate 后降到 0.05s。
  这是本项目最大的单点优化，改动只有 10 行。
- **活动边表（AET）**：扫描线每行只处理相交边，避免 O(行数×边数)。
- **zlib level 6 而不是 9**：快一倍，文件只大 15%。
- 抗锯齿**不能**依赖「输出大图 + 查看器缩小」：必须在光栅化阶段做亚像素覆盖率，
  否则 1:1 看边缘是硬的（实测二值填充 0 级灰度，覆盖率 231 级）。
- 大半径圆弧、近水平曲线还需要 ss≥3 补纵向采样。
- 大尺寸半透明填充是性能陷阱：全屏暗角椭圆让 16:9 图从 2s 涨到 12s；改成四边窄带渐变后回到 2s。
- 文字有字形缓存；改文案重渲染约 0.5–1s。

### 静态层缓存：做了，但实测不划算（默认关闭）

实现是把 scene/motifs 这类与文案无关的内容缓存成位图，改文案时只重绘文字层。
实测（1080×1440 @ ss=3，静态 774 ops / 动态 227 ops）：

| 情况 | 耗时 |
|---|---|
| 冷启动（写缓存） | 3.03s |
| 缓存命中 | 1.47s |
| **禁用缓存（全量重绘）** | **1.31s** |

**缓存反而慢 0.16s。** 原因：静态层是几何平涂、渲染本来就只要 0.3–0.4s，
而 40MB 位图的读写（即使 store 不压缩）也要 0.4s 量级——IO 成本和渲染成本相当。

结论：`--cache` 默认关闭。只有满足**「静态层渲染远慢于 40MB IO」**时才可能划算，
例如静态层含大量渐变/裁剪的精细插画、或画布尺寸较小（低 ss）。开启前建议实测。

分层标记（`Canvas.use_layer`）本身仍有价值：将来做局部重绘、增量导出都依赖它。

## 迭代技巧

- 每次只改一处再渲染，避免「改了五个参数不知道哪个起作用」。
- 区块级检查：先只渲染可疑区块（临时把 layout 的其他块注释掉），比整图看更快定位。
- 用 `check.py` 的 6 类断言替代肉眼：越界、对比度、最小字号、色数、缺字、slot 完整性。
- **不要用 `read_image` 判断 1–2px 的缺陷**：预览缩放会产生假缺口/假毛刺。

## 常见坑

| 现象 | 原因 | 解法 |
|---|---|---|
| 花/云被挖空 | evenodd 填充多轮廓 | 用 `rule="nonzero"` |
| 竖排顺序反了 | y 方向写反 | 竖排 y 递增（画布 y 向下） |
| 文字越界 | 居中时传入左边而非中心 | `_text` 已按 box 计算中心点 |
| A4 出图 52 秒 | print 档 ss 过高 | print 档强制 ss=1 |
| 暗色主题边缘发亮 | 暗角用了 fg 色 | 暗角固定用黑色 |
| 16:9 正文一行 80 字 | 版心未限宽 | 骨架对宽屏正文限宽 h×0.62 |
